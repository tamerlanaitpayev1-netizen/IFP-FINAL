Scalability & Conclusion

Production Scaling Roadmap & Key Takeaways

Honest Horizontal Scaling Architecture

Current in-process ConcurrentDictionary state + System.Threading.Timer excels on a single university/department server. Scaling cleanly across multiple behind-load-balancer nodes requires:

  • 1. SignalR Redis Backplane / Azure SignalR Service for cross-node WebSocket fanout.
  • 2. Distributed Room State in Redis (hashes & distributed timers) replacing in-process memory.
  • 3. PostgreSQL Migration replacing SQLite for multi-writer cluster concurrency.
