Честная архитектура масштабирования

Текущее решение идеально для 1 выделенного узла аудитории/ВУЗа (внутренний ConcurrentDictionary + System.Threading.Timer). Для кластера из N серверов предусмотрен переход:

  • 1. SignalR Redis Backplane / Azure SignalR Service — маршрутизация WebSocket между нодами.
  • 2. Redis Distributed Room State — вынос состояния комнат и распределённых таймеров из памяти процесса.
  • 3. PostgreSQL — замена SQLite для многопоточной записи с кластера.
